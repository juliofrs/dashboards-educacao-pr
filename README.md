# O Funil da Educação Básica no Paraná 🎓📊

Este repositório contém os scripts e a análise visual desenvolvidos para o projeto de Visualização de Dados. O objetivo é explorar a dinâmica demográfica e a transição de matrículas entre as redes de ensino (Municipal, Estadual, Federal e Privada) no estado do Paraná ao longo da última década (2016-2025).

## 🎯 Objetivo do Projeto
Construir uma narrativa visual impactante em um único painel (formato A4) que evidencie os gargalos e as mudanças estruturais no fluxo de alunos, com foco especial na absorção da demanda do Ensino Médio. Toda a construção gráfica é rigorosamente baseada nos **Princípios de Excelência Gráfica de Edward Tufte**, priorizando a alta proporção tinta-dado e eliminando ruídos visuais (*chartjunk*).

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** R
* **Ambiente:** RStudio
* **Pacotes Principais:** `ggplot2`, `dplyr`, `ggthemes` (theme_tufte) e `patchwork`

## 🗂️ Os Dados
A base original compreende mais de 15.000 observações com detalhamento de matrículas por município, idade e etapa de ensino (da Creche ao Ensino Médio), permitindo uma visão granular da estrutura educacional paranaense.
